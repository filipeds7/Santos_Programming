# Santos Programming — Portfólio

Site de portfólio responsivo inspirado no layout enviado.

## Arquivos
- `index.html` — estrutura do site
- `style.css` — visual, responsividade e animações simples
- `script.js` — menu mobile
- `assets/portfolio-reference.png` — imagem de referência

## Personalização
1. Abra `index.html`.
2. Troque os links `https://wa.me/5500000000000` pelo seu número real de WhatsApp.
3. Substitua os projetos de exemplo pelos seus links reais.
4. Para usar imagens reais dos projetos, coloque-as em `assets/` e substitua os blocos `.project-image` por `<img>`.

## GitHub Pages
Envie estes arquivos para um repositório do GitHub e ative **Settings → Pages → Deploy from a branch**, escolhendo a branch principal e a pasta `/root`.
